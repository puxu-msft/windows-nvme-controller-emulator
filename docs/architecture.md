# 系统架构设计

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    用户应用程序                          │
├─────────────────────────────────────────────────────────┤
│                    文件系统 (NTFS)                       │
├─────────────────────────────────────────────────────────┤
│                    卷管理器                              │
├─────────────────────────────────────────────────────────┤
│                    磁盘类驱动                            │
├─────────────────────────────────────────────────────────┤
│              StorPort Miniport 驱动                      │
├─────────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────────┐  │
│  │           Virtual NVMe Driver (本项目)             │  │
│  │  ┌─────────────┐  ┌─────────────┐  ┌───────────┐  │  │
│  │  │ NVMe 控制器 │  │ 命令处理器  │  │ 存储后端  │  │  │
│  │  │   模拟层    │  │             │  │  适配器   │  │  │
│  │  └─────────────┘  └─────────────┘  └───────────┘  │  │
│  └───────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│              存储后端 (内存 / 文件 / VHD)                │
└─────────────────────────────────────────────────────────┘
```

## 核心组件

### 1. 驱动入口模块 (Driver Entry)
- DriverEntry 初始化
- 设备对象创建
- WDF 框架集成

### 2. NVMe 控制器模拟器 (Controller Emulator)
- 控制器寄存器模拟
- 控制器状态机管理
- 能力报告 (Capabilities)

### 3. 命令处理器 (Command Processor)
- Admin Command 队列处理
- I/O Command 队列处理
- 完成队列管理

### 4. 存储后端适配器 (Storage Backend)
- 内存后端：使用系统内存作为存储
- 文件后端：使用文件作为存储介质
- 可扩展接口设计

### 5. 配置管理器 (Configuration Manager)
- 注册表配置读取
- 运行时参数管理
- 命名空间配置

## 驱动类型选择

采用 **StorPort Miniport** 驱动模型：
- 与 Windows 存储栈完美集成
- 自动获得热插拔、电源管理支持
- 简化的开发模型
- 良好的性能特性
